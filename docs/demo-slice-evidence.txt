ENVIRONMENT LIMITATION
  Playwright's browser could not be installed: `npx playwright install chromium`
  requires system packages that need root, which this sandbox does not have.
  The same flow was therefore verified over real HTTP against the real servers
  (above) rather than through a real browser DOM.
  The Playwright spec is committed at apps/web/e2e/demo-slice.spec.ts.
  To run it locally:  cd apps/web && npx playwright install chromium && npx playwright test

  `npm install` also cannot complete inside the mounted volume (it cannot rename
  directories). It works normally on an ordinary filesystem.
